# Vision

Build a simple, cross-platform habit tracker that helps people build lasting habits through flexible scheduling and a long-term consistency score instead of rigid streaks.

## Problem

Current habit trackers often:

1. aren't available across desktop and mobile with seamless sync
2. don't support flexible scheduling (X times in Y days/weeks/months)
3. emphasize ideal streaks without a single skipped day
4. become bloated productivity suites
5. create unnecessary friction before users can start

## Target users

People building personal habits who value simplicity, flexibility, and cross-device access.

## Product principles

- Low friction
- Local first
- Flexible scheduling
- Consistency over perfection
- Available everywhere
- Focused solely on habit tracking

## Success

Users can:

- create habits in seconds
- log today's progress in seconds
- understand their long-term consistency at a glance
- use the same app on desktop and mobile

## Non-goals

- Task management
- Daily planning
- Gamification
- Social network features
- AI coaching
