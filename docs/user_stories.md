## Create habits

- As a user, I want to add habits to the app so that I can start tracking a behavior I want to build
- As a user, I want to be able to set a flexible habit schedule (X times in Y days, weeks, or months) so that it matches my routine

## View and complete habits

- As a user, I want to see all my habits on a shared timeline with their day statuses so that I can understand recent progress and know what needs my attention today
- As a user, I want to see the last few days of each habit so that
    - I remember whether I've recently completed it
    - I am inspired by my progress
- As a user, I want to record or correct completion for today and recent past days so that my history remains accurate
- As a user, I want to reveal dates in the timeline when I need them so that I can identify a day without the timeline always feeling cluttered

## Review progress

- As a user, I want to view and edit a habit's full history so that I can review my past progress and keep the record accurate
- As a user, I want to see a habit's strength so that I can understand how established the habit has become

## Update habits

- As a user, I want to edit existing habits so that
    - I can update schedule
    - I can update the habit details and keep it meaningful
    - I can correct mistakes
- As a user, I want to give each habit a color so that I can distinguish my habits at a glance
- As a user, I want to delete habits that I no longer need so that my habit list stays relevant

## UX

- As a user, I want to install the app so that I get the app-like experience (separate screen/window, app icon, no browser UI)
- As a user, I want my habit data to be saved automatically so that it isn't lost when I close the browser/app
- As a user, I want to choose between system, light, and dark themes so that the app is comfortable to use in different environments
- As a user, I want in-app notifications about actions the app has completed or will perform so that I stay informed without interrupting my work
